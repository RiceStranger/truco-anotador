# Anotador de Truco
Sencillo anotador open source de Truco para Android. Permite cambiarle el nombre a los jugadores y añadir y quitar puntaje de a 5 puntos. Permite sumar puntaje apretando la mitad superior, y quitar apretando la inferior.
<br>Hasta el momento solo permite jugar de a 30, pero pienso añadir más funciones en el futuro, como notificaciones al ganador, un modo que avise cuando toque pica pic (configurable) y, especialmente, un modo para poder <b>anotar en Truco Gallo</b> (para partidos de a tres).

Hecho en Godot 4.2
